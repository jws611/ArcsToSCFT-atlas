# ArcsToSCFT Theory Atlas

Public read-only snapshot generated 2026-09-19T02:52:39+00:00.

131 theories with stored indices, flavor characters and KLS schemes. Every dataset retains its verification cutoff, arithmetic and limitations. Partial results and finite-field evidence are not characteristic-zero completion proofs.

The research database, execution logs and local services are not included. JSON files here are publication exports, not the authoritative research store.

GitHub Pages serves the root of this repository. No Python server, login or Tailscale is required. The displayed results change only when a new snapshot is published.
